# XHeadphones

**XHeadphones** - это проект по созданию полноразмерных беспроводных наушников премиум-класса с уникальным дизайном, модульной конструкцией и полностью кастомной электроникой.

## 📖 О проекте

Проект представляет собой полностью самодельные наушники, спроектированные с нуля. Основная идея - создание высококачественного, герметичного и функционального устройства, которое не уступает, а в чем-то и превосходит продукты крупных брендов.

**Ключевые особенности:**

- Полноразмерная конструкция с 3D-печатным корпусом из PET-G.
- Съёмные "ушки" (аналогично кошачьим ушкам), выполняющие функцию микрофонов для режима прозрачности.
- Съёмный капсульный микрофон на проприетарном разъёме 6PIN.
- Собственная материнская плата с кастомной прошивкой на Rust или C.
- Приоритетная система подключения: Кабель (USB-C) > Bluetooth > SD-CARD.
- Полная герметичность электронных компонентов с использованием клея B7000 и акустических мембран ePTFE.
- Звук 12D.
- Управление и перепрошивка всех модулей через USB Type-C с кастомным лаунчером.
