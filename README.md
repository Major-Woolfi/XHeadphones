# XHeadphones

Кастомные беспроводные наушники с **автономной работой**, `Bluetooth Classic`
(`A2DP`), **режимом прозрачности** и встроенным плеером. Построены на
`ESP32-WROVER-IE-N16R8` с самописной микро-ОС поверх `FreeRTOS`.

## Описание

XHeadphones - это наушники **закрытого типа**, которые умеют работать без
телефона: плеер читает музыку с `microSD`, Bluetooth работает и как приёмник
(`Sink`), и как передатчик (`Source`), а внешние микрофоны дают режим
прозрачности. Проект закрытый по железу и открытый по документации: вся схема,
карта пинов, `BOM` и пайплайн сборки описаны в `DOCS/`.

Приоритет источников при переключении: кабель `USB-C`, затем `Bluetooth`,
затем карта памяти.

## Ключевые возможности

- **Bluetooth-приёмник (`Sink`)**: приём музыки с телефона по `A2DP`.
- **Автономный плеер**: воспроизведение `MP3`, `FLAC` и `WAV` с `microSD`.
- **Режим прозрачности**: внешние микрофоны передают звук наружу.
- **Режим шумоподавления**: *программная* обработка основных микрофонов.
- **Быстрая зарядка**: `USB-C` с `PD` и `QC` до 18 Вт, `IP2726` и `IP2326`.
- **Две батареи** 1000 мАч в чашах и **две 500 мАч** в ушках: балансировка,
  защита, Power Path Management.
- **Съёмные ушки**: два комплекта - с батареей и без.
- **`OTA`-обновления** прошивки по `Wi-Fi`.
- **Проприетарные разъёмы `6-pin`** для ушек и съёмного микрофона.

> **Оговорка.** Режим шумоподавления - это программная обработка сигнала
> микрофонов, а не гибридный `ANC` с акустической обратной связью. Требования
> к глубине подавления шума в документации не зафиксированы.

## Технические характеристики

| Параметр | Значение |
| --- | --- |
| Модуль | `ESP32-WROVER-IE-N16R8` |
| Ядра | 2 × `Xtensa LX6`, до 240 МГц |
| Память | 16 МБ `Flash`, 8 МБ `PSRAM` |
| Bluetooth | Classic 4.2 `BR/EDR`, `A2DP`, `AVRCP`, `BLE` |
| Wi-Fi | `802.11 b/g/n`, только для `OTA` |
| ЦАП | `PCM5102A`, 32 бит, до 384 кГц, `SNR` 113 дБ |
| АЦП прозрачности | `PCM1808`, 24 бит, `SNR` 99 дБ |
| Усилитель | `OPA1622`, `THD+N` -119.2 дБ, питание ±5 В |
| Rail splitter | `TLE2426`, виртуальная земля для `OPA1622` |
| Микрофоны | 5 шт., аналоговые капсульные |
| Распределение микрофонов | 2 в чашах, 2 в ушках, 1 съёмный |
| Динамики | 2 × 40 мм, 32 Ом, 20 Гц - 20 кГц, премиум-класс |
| Хранилище | `microSD`, `FAT32` |
| Зарядка | `USB-C`, `PD` и `QC` до 18 Вт |
| Модули зарядки | `IP2726` и `IP2326` |
| Батареи чаш | `2S Li-Po`, 2 × 3.7 В 1000 мАч |
| Батареи ушек | 2 × 3.7 В 500 мАч, комплект 1 |
| Питание платы | `+3.3 В` до 2 А, `TPS63070` |
| Автономность | 6-8 часов актив, 14-18 часов `idle` |
| Корпус | `PET-G`, 3D-печать, чаши 9 см |
| Масса | цель 200-300 г, максимум 400 г |

> **Оговорка.** Параметры `IP2726`, `IP2326`, `ETA6003`, `LM27762` и `TLE2426`,
> а также энергобаланс - проектная гипотеза. Значения подтверждаются по
> `datasheet` выбранных модулей и замерами на прототипе.

Полный список: [SPECIFICATIONS.md](DOCS/SPECIFICATIONS.md).

## Архитектура

```text
+-------------------------------------------------------------+
|                    ESP32-WROVER-IE-N16R8                    |
|                  (FreeRTOS + микро-ОС)                     |
+-----------+-------------------+-----------------+-------------+
            | I2S               | GPIO / I2C      | microSD
            v                   v                 v
     +-------------+     +-------------+     +-------------+
     |  PCM5102A   |     | PCM1808     |     |   FAT32     |
     |    (DAC)    |     |   (ADC)     |     |  MP3/FLAC   |
     +------+------+     +------+------+     +-------------+
            |                   ^
            v                   |
     +-------------+     +-------------+
     |   OPA1622   |     |  капсульные |
     |  (усилитель)|     | микрофоны   |
     +------+------+     +-------------+
            v
     +-------------+
     |  Динамики   |
     +-------------+
```

Питание: `USB-C` -> `IP2726` (`PD` и `QC`) -> `IP2326` (`BMS` и заряд) ->
батареи `2S` -> Power Path (`ETA6003` и `AO3401`) -> `TPS63070` -> `+3.3 В`,
boost `LM27762` -> `±5 В` для `OPA1622`.

Подробности: [POWER.md](DOCS/POWER.md), [ARCHITECTURE.md](DOCS/ARCHITECTURE.md).

## Конструкция

- **Чаши**: диаметр 9 см и высота 3 см, ободок шириной 4 см и толщиной 1 см.
- **Амбушюры**: внешний диаметр 9 см, выемка под ухо 7 см, толщина 3.5 см.
- **Три слоя амбушюра**: крупная сетка с надписями `L` и `R`, мелкая тканевая
  сетка, поролоновая проставка 2-4 мм.
- **Ушки съёмные**: комплект 1 высотой 5 см с батареей, комплект 2 высотой
  3 см без батареи. Каждый комплект - пара.
- **Герметичность**: клей `B7000` по всем стыкам, резиновые прокладки на
  разъёмах, акустические мембраны `ePTFE` на микрофонах.

Полное описание: [CONCEPT.md](DOCS/CONCEPT.md).

## Управление

| Кнопка | Расположение | Действие |
| --- | --- | --- |
| Питание | Левая чаша | Включение и выключение |
| Режим | Левая чаша | Шумоподавление и прозрачность |
| Источник | Левая чаша | `Bluetooth` и `SD`-карта |
| Воспроизведение | Левая чаша | Пауза и продолжение |
| Вперёд | Левая чаша | Следующий трек |
| Назад | Левая чаша | Предыдущий трек |
| Индикация | Ушки | Заряд батареи каждого ушка |

Режим по умолчанию - **шумоподавление**, источник по умолчанию -
**`Bluetooth`**. Полная карта: [PINOUT.md](DOCS/PINOUT.md).

## Прошивка и программное обеспечение

Прошивка написана на `C` поверх `ESP-IDF` и `FreeRTOS`. Микро-ОС состоит из
**шести задач**: `task_bt`, `task_audio`, `task_decode`, `task_sd`,
`task_input`, `task_power`. Обмен данными - очереди `FreeRTOS` и семафоры,
аудиобуфер размещается в `PSRAM`.

| Документ | Содержание |
| --- | --- |
| [SOFTWARE.md](DOCS/SOFTWARE.md) | Структура проекта, задачи, очереди |
| [FIRMWARE.md](DOCS/FIRMWARE.md) | Модули прошивки, лаунчер, обновление |
| [PINOUT.md](DOCS/PINOUT.md) | Карта пинов `ESP32` и обвязка кнопок |
| [PRODUCTION.md](DOCS/PRODUCTION.md) | Прошивка по `USB` и `OTA`, `Flash` |

> **Оговорка.** Исходников прошивки в репозитории пока нет: каталог `FIRMWARE/`
> содержит только скрипты `BUILD.sh` и `BUILD.bat`, которые начнут работу после
> создания `FIRMWARE/CMakeLists.txt` и файлов компонентов.

## Быстрый старт

1. Заказать компоненты по таблице [BOM.csv](DOCS/BOM.csv).
2. Развести платы по [PINOUT.md](DOCS/PINOUT.md) и [POWER.md](DOCS/POWER.md).
3. Собрать и проверить платы по [PRODUCTION.md](DOCS/PRODUCTION.md).
4. Прошить `ESP32` и собрать микро-ОС по [SOFTWARE.md](DOCS/SOFTWARE.md).
5. Напечатать корпус и установить электронику по
   [CONCEPT.md](DOCS/CONCEPT.md).
