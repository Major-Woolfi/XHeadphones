# Технические характеристики XHeadphones

## 1. Общие характеристики

| Параметр | Значение |
| --- | --- |
| **Тип** | Полноразмерные беспроводные наушники закрытого типа |
| **Материал корпуса** | PET-G (3D-печать) |
| **Цветовые схемы** | Black edition (основной цвет - черный) и White edition (основной цвет - белый), акцентные цвета - синий/розовый (т.е. всего доступно 4 цветовые схемы) |
| **Вес** | Целевой: 200–300 г (максимум 400 г) |
| **Герметичность** | Все стыки заклеиваются клеем B7000, а разъёмы дополнительно оснащаются резиновыми прокладками. Технические отверстия оснащены акустической водоотталкивающей мембраной ePTFE. |
| **Комплектация** | Наушники (1 шт.), съёмный микрофон (1 шт.), 2 пары съёмных ушек (1 пара с АКБ, 1 пара без АКБ) |

## 2. Акустическая система

| Параметр | Значение |
| --- | --- |
| **Тип динамиков** | Стерео, 2 шт. (по одному в каждой чаше) |
| **Диаметр динамиков** | ~40 мм (уточняется при подборе) |
| **Импеданс** | 32 Ом (типовой) |
| **Частотный диапазон** | 20 Гц – 20 кГц (целевой) |
| **Звук** | Стерео, поддержка 12D объемного звучания |
| **Реализация 12D** | Аппаратная (DSP-чип) или программная (обработка на MCU) |
| **Акустическое оформление** | Закрытый корпус с тройной сеткой и поролоновой проставкой |

### Конструкция амбушюр

- **Диаметр:** 9 см
- **Внутренняя выемка:** 7 см
- **Толщина:** 3,5 см
- **Материал:** мягкий, многослойный
- **Сетка:** крупная (отверстия ~0,5 см, с надписями L/R) → мелкая → поролон 2–4 мм → технические отверстия в чаше (диаметр 5 мм)

## 3. Микрофоны

| Параметр | Значение |
| --- | --- |
| **Основные микрофоны** | 2 шт., по одному снизу в каждой чаше (для шумоподавления) |
| **Тип** | Капсульные, высокой чувствительности, с параллоновой защитой от шумов |
| **Съёмный микрофон** | 1 шт., MEMS, полностью экранированный, крепление на проприетарный разъём 6PIN |
| **Микрофоны в ушках** | По одному в каждом ушке (для режима прозрачности) |

## 4. Управление и разъёмы

### Левая чаша (внешняя сторона)

- **USB Type-C** (зарядка, данные, управление, перепрошивка, обновление, подключение)
- **Кнопка режима работы:** Шумоподавление (по умолчанию) / Прозрачность
- **Кнопка источника:** Bluetooth (по умолчанию) / SD-CARD
- **Кнопка питания:** Вкл / Выкл
- **Кнопки управления:** Вперёд, Пауза/Продолжить, Назад

### Правая чаша (внешняя сторона)

- **Проприетарный разъём 6PIN** для съёмного микрофона

### Снизу (обе чаши)

- По одному отверстию для основных микрофонов (с параллоновой проставкой)

### На ободке

- **Проприетарные разъёмы 6PIN** для ушек (2 шт.)

### Тип разъёмов

- 6-pin, похожие на AMD-сокеты, но с "пеньками" на ответной части
- Влагозащита: резиновые уплотнители на всех внешних контактах

## 5. Питание

| Параметр | Значение |
| --- | --- |
| **Тип АКБ** | Литий-полимерные (Li-Po) |
| **Количество АКБ** | 2 или 4 (по 1 в каждом ушке + по 1 в каждой чаше) |
| **Приоритет разряда** | Сначала ушки, затем наушники |
| **Приоритет зарядки** | Сначала наушники, затем ушки |
| **Балансировка** | Автоматическая между всеми АКБ |
| **Время работы** | От 24 часов при постоянной нагрузке |
| **Индикация заряда** | Светодиод в каждом ушке (независимые) |

### Индикация (цвета)

- **Постоянный розовый/синий:** 100–50%
- **Дыхание розовый/синий:** 50–20%
- **Красный:** 20–1%
- **Выключен:** 0% или не подключено

## 6. Подключение и хранение данных

| Параметр | Значение |
| --- | --- |
| **Приоритет подключения** | 1. Кабель (USB Type-C) → 2. Bluetooth → 3. SD-карта |
| **Bluetooth** | Версия 5.x (уточняется при выборе модуля) |
| **Слот памяти** | microSD (распаян на плате) |
| **Управление музыкой с SD** | Через подключение к другому устройству по USB Type-C |
| **Перепрошивка модулей** | Через USB Type-C с кастомным лаунчером |

## 7. Программное обеспечение

| Параметр | Значение |
| --- | --- |
| **Язык прошивки** | Rust или C (в зависимости от MCU) |
| **Архитектура** | Модульная, с возможностью обновления отдельных модулей (BT, DSP, MCU) |
| **Кастомный лаунчер** | Поставляется с проектом для управления и перепрошивки |

## 8. Условия эксплуатации

| Параметр | Значение |
| --- | --- |
| **Защита от воды** | Герметизация, акустические мембраны ePTFE (допускается погружение в воду на короткое время) |
| **Рабочая температура** | -15°C … +60°C (целевая) |
