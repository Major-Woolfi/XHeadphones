## 1. Общие характеристики

| Параметр | Значение |
| --- | --- |
| Тип | Полноразмерные наушники закрытого типа |
| Материал корпуса | `PET-G`, 3D-печать |
| Цветовые схемы | `Black` и `White`, акценты синий и розовый |
| Количество схем | 4 |
| Чаши | Диаметр 9 см, высота 3 см |
| Ободок | Ширина 4 см, толщина 1 см, подкладка 0.5 см |
| Масса | Цель **200-300 г**, максимум **400 г** |
| Герметичность | Клей `B7000`, прокладки, мембраны `ePTFE` |
| Комплектация | Наушники, микрофон, 2 пары ушек, кабель, инструкция |

## 2. Акустическая система

| Параметр | Значение |
| --- | --- |
| Тип динамиков | Стерео, 2 шт., по одному в каждой чаше |
| Диаметр динамиков | 40 мм, поставка с динамиками премиум-класса |
| Импеданс | 32 Ом |
| Частотный диапазон | 20 Гц - 20 кГц, целевой |
| Звук | Стерео, пространственный звук `12D` |
| Реализация `12D` | `DSP` или программная обработка на `MCU` |
| Акустическое оформление | Закрытый корпус, тройная сетка, поролон |
| ЦАП | `PCM5102A`, 32 бит, до 384 кГц, `SNR` 113 дБ |
| АЦП тракта прозрачности | `PCM1808`, 24 бит, `SNR` 99 дБ |
| Усилитель | `OPA1622`, `THD+N` -119.2 дБ, до 145 мА |
| Rail splitter | `TLE2426`, виртуальная земля для `OPA1622` |

> **Оговорка.** Термин *пространственный звук `12D`* технически не определён:
> набор эффектов и целевая характеристика не зафиксированы. Выбор между
> аппаратным `DSP` и программной обработкой на `MCU` влияет на `BOM`, на
> энергобаланс и на задержку тракта прозрачности.

## 3. Микрофоны

| Параметр | Значение |
| --- | --- |
| Основные микрофоны чаш | 2 шт., снизу чаш, для `ANC` и прозрачности |
| Микрофоны ушек | 2 шт., по одному в каждом ушке, для прозрачности |
| Съёмный микрофон | 1 шт., экранированный, разъём `6-pin` |
| Тип | Капсульные аналоговые, высокой чувствительности |
| Защита | Параллоновая проставка от внешних шумов |
| Интерфейс | Аналоговый вход `PCM1808` |

> **Оговорка.** Микрофоны чаш и ушек работают как *капсульные*, без
> цифровых `MEMS` и без отдельного тракта `ANC`. Глубина подавления шума и
> допустимая задержка прозрачности не измерены.

## 4. Управление и разъёмы

### 4.1 Левая чаша

| Элемент | Назначение |
| --- | --- |
| `USB Type-C` | Зарядка, данные, перепрошивка, обновление |
| Кнопка питания | Включение и выключение |
| Кнопка режима | Шумоподавление (по умолчанию) и прозрачность |
| Кнопка источника | `Bluetooth` (по умолчанию) и `SD`-карта |
| Кнопка паузы | Пауза и продолжение |
| Кнопка вперёд | Следующий трек |
| Кнопка назад | Предыдущий трек |

### 4.2 Правая чаша

| Элемент | Назначение |
| --- | --- |
| Разъём `6-pin` | Съёмный микрофон |

### 4.3 Ободок и низ чаш

| Элемент | Назначение |
| --- | --- |
| Разъёмы `6-pin` на ободке, 2 шт. | Ушки |
| Отверстия снизу обеих чаш | Основные микрофоны чаш |

### 4.4 Тип разъёмов

- `6-pin`, по форме похожие на сокеты `AMD`, но с "пеньками" на ответной части.
- Резиновые уплотнители на всех внешних контактах.
- 6 линий: питание ушек, аудио микрофона, данные, земля, детект ушек.

> **Оговорка.** В перечне указаны пять назначений для шести линий. Назначение
> шестой линии (`6-pin`) не определено и должно быть зафиксировано до
> разводки платы: это влияет на распиновку `Pogo-Pin` и на прошивку ушек.

## 5. Питание

| Параметр | Значение |
| --- | --- |
| Тип АКБ | Литий-полимерные `Li-Po` |
| Батареи чаш | 2 × 3.7 В 1000 мАч, соединение `2S` |
| Батареи ушек | 2 × 3.7 В 500 мАч, комплект 1, заряд через `Pogo-Pin` |
| Приоритет разряда | Сначала ушки, затем чаши |
| Приоритет зарядки | Сначала чаши, затем ушки |
| Балансировка | Автоматическая, `IP2326` |
| Зарядка | `USB-C`, `PD` и `QC` до 18 Вт |
| Питание платы | `+3.3 В` до 2 А, buck-boost `TPS63070` |
| Питание усилителя | `±5 В` от `LM27762`, земля `TLE2426` |
| Быстрый заряд | `IP2726` как `PD`-триггер, до 20 В 100 Вт на входе |
| Защита | Перезаряд, переразряд, КЗ, `NTC` |
| Индикация заряда | Светодиод в каждом ушке, независимые |

> **Оговорка.** Конфигурация `2S` на `IP2326` требует проверки: модуль
> выпускается в вариантах `2S` - `5S` с перемычками, и работоспособность
> балансировки двух банок подтверждается только замерами. `LM27762` выбран как
> инвертор для `±5 В`, его ток и КПД проверяются по `datasheet` и на макете.

### 5.1 Энергобаланс

| Режим | Потребление | Время работы |
| --- | --- | --- |
| `BT Sink` со звуком | около 240 мА | 6-7 часов |
| Плеер с `SD` | около 200 мА | 7-8 часов |
| Прозрачность | около 220 мА | 7-8 часов |
| `Idle` с включённым `BT` | около 100 мА | 14-18 часов |

Расчёт по батареям чаш: `2S` 7.4 В и 1 А·ч дают 7.4 Вт·ч, после потерь
Power Path и `DC-DC` на нагрузку приходит около 6.7 Вт·ч, при среднем
потреблении 0.8 Вт это 8.3 часа теоретически. Батареи ушек питают только
светодиоды индикации, на время работы чаш они не влияют.

> **Оговорка.** Значения - расчётные, без замеров на прототипе. Реальное время
> работы зависит от энергопотребления `BT`-стека, работы `microSD` и потерь на
> `DC-DC`. Батареи ушек не входят в расчёт, они питают только индикацию.

### 5.2 Индикация заряда ушек

| Уровень | Цвет |
| --- | --- |
| 100-50% | Ровный розовый или синий |
| 50-20% | Пульсация розовым или синим |
| 20-1% | Красный |
| 0% или ушки не подключены | Не горит |

## 6. Подключение и хранение данных

| Параметр | Значение |
| --- | --- |
| Приоритет источников | 1. `USB-C`, 2. `Bluetooth`, 3. `SD`-карта |
| Bluetooth | Classic 4.2 `BR/EDR`, `A2DP` и `AVRCP`, плюс `BLE` |
| Wi-Fi | `802.11 b/g/n`, только для `OTA` |
| Слот памяти | `microSD`, распаян на плате, `FAT32` |
| Форматы | `MP3`, `FLAC`, `WAV` |
| Управление на карте | Через `USB Type-C` с внешнего устройства |
| Обновление прошивки | `USB Type-C` кастомным лаунчером |
| `OTA` | `Wi-Fi`, точка доступа или домашняя сеть |

> **Оговорка.** Профиль `A2DP Source` на ESP32 Classic требует проверки:
> стек `A2DP Source` поддерживается ограниченно, совместимость с внешними
> аудиоустановками подтверждается только тестом. `BLE` заявлен, но в текущей
> документации не используется.

## 7. Программное обеспечение

| Параметр | Значение |
| --- | --- |
| Язык прошивки | `C` поверх `ESP-IDF` |
| Ядро | `FreeRTOS`, микро-ОС из шести задач |
| Архитектура | Модульная, обновление блоков `BT`, `DSP`, `MCU` |
| Обновление модулей | `USB Type-C`, кастомный лаунчер `XHeadphones` |
| Инструменты | `ESP-IDF`, `Python`, `esptool` для загрузки образа |

## 8. Условия эксплуатации

| Параметр | Значение |
| --- | --- |
| Защита от воды | Герметизация и мембраны `ePTFE`, кратковременно |
| Рабочая температура | От -15 °C до +60 °C, целевая |
| Хранение | Без батарей при хранении более месяца |

> **Оговорка.** Класс защиты не заявлен: изделие не рассчитано на погружение и
> длительную работу под дождём. Рабочий диапазон температур - целевой, без
> испытаний.
