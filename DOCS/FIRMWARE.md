# Прошивка XHeadphones

## 1. Общая архитектура

Прошивка написана на Rust или C (в зависимости от выбранного микроконтроллера). Архитектура модульная, что позволяет обновлять отдельные компоненты (Bluetooth-модуль, DSP, MCU) независимо.

### Основные модули (всё на 1 плате)

- **MCU Core:** управление питанием, кнопками, индикацией, приоритетами подключения.
- **Audio DSP:** обработка звука, реализация 12D объемного звучания.
- **Bluetooth Stack:** сопряжение, передача аудио, управление.
- **USB Stack:** зарядка, передача данных, управление, перепрошивка, обновление, подключение.
- **SD-Card Controller:** чтение и воспроизведение файлов с microSD.
- **Power Management:** контроль АКБ, балансировка, приоритеты разряда/зарядки.

## 2. Логика работы

### 2.1. Приоритеты подключения

1. **Кабель** (USB Type-C) - воспроизведение с подключенного устройства.
2. **Bluetooth** - если нет кабеля, но есть активное BT-соединение - воспроизведение с подключенного устройства.
3. **Карта памяти** - если нет ни кабеля, ни BT-соединения - воспроизведение с карты памяти.

### 2.2. Управление питанием

- **Приоритет разряда:** Сначала разряжаются АКБ в ушках, затем - в наушниках.
- **Приоритет зарядки:** Сначала заряжаются АКБ в наушниках, затем - в ушках.
- **Балансировка:** Автоматическая балансировка заряда между всеми АКБ.

### 2.3. Режимы работы

- **Шумоподавление (ANC):** по умолчанию.
- **Прозрачность:** использование микрофонов в ушках и основных микрофонов.
- **Выключено.**

### 2.4. Индикация

- Светодиоды в ушках отображают уровень заряда (цвета: розовый/синий, красный).
- При подключении к USB - индикация зарядки.

## 3. Перепрошивка модулей

- Все модули (BT, DSP, MCU) могут быть перепрошиты через USB Type-C.
- Для этого используется кастомный лаунчер XHeadphones, поставляемый с проектом.
- Лаунчер обеспечивает:
  - Обновление прошивок (как отдельных компонентов, так и наушников в целом).
  - Настройку параметров звука.
  - Диагностику компонентов.
  - Управление режимами.
  - Управление данными на карте памяти.
  - Возможность перепрошивки (как отдельных компонентов, так и наушников в целом).

## 4. Кастомный лаунчер

- **Платформа:** Windows / Linux.
- **Функции:**
  - Прошивка MCU, BT-модуля, DSP и multi-patch (прошивка всех модулей разом через общий образ прошивки).
  - Настройка эквалайзера, 12D-эффектов.
  - Обновление через USB Type-C.
  - Мониторинг состояния АКБ.
  - Сброс настроек.
  - Управление режимами.
  - Управление данными на карте памяти.

## 5. Зависимости и инструменты

- **Компилятор:** Rust (cargo) или C (GCC).
- **SDK:** зависит от выбранного MCU (ESP-IDF, STM32Cube, и т.д.).
- **Отладка:** JTAG/SWD (при наличии).

## 6. Планы по развитию

- Поддержка OTA-обновлений (через Bluetooth).
